# Petición editorial reutilizable

Crea un libro práctico en español para una persona sin conocimientos técnicos que quiera entender y construir automatizaciones de negocio con Zapier, Make y n8n. Define una ruta progresiva con resultados de aprendizaje, fundamentos, proyectos y criterios de evaluación. Enseña desde cero procesos, datos, JSON, HTTP, APIs, webhooks, autenticación, JavaScript, nociones de Python y SQL, y el modelo de ejecución específico de cada plataforma.

Incluye diez laboratorios por plataforma, con requisitos, pasos concretos, código completo cuando corresponda, datos ficticios, resultados esperados, pruebas de fallo, soluciones y variantes. Reutiliza un mismo contrato de negocio para comparar plataformas. Agrega un laboratorio local reproducible para practicar paginación, errores, reintentos, idempotencia y concurrencia sin depender de servicios reales.

Desarrolla también aprobaciones humanas, seguridad, minimización de datos, credenciales, monitoreo, conciliación, costos, capacidad, documentación, copias, restauración y mantenimiento. Incluye IA aplicada con salidas estructuradas, evaluación, límites de agentes, RAG y MCP, distinguiendo con claridad simuladores y modelos reales.

Usa fuentes oficiales consultadas en la fecha de preparación. Distingue los principios estables de interfaces, planes y versiones que deberán verificarse durante el año objetivo. No presentes como comprobadas funciones futuras ni integraciones que no se ejecutaron. Entrega un PDF navegable y un paquete editable con ejemplos, pruebas y plantillas.
